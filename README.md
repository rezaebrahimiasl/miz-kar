# میز کار رضا

دستیار شخصی موبایلی (فارسی، تاریخ شمسی). داده‌ها فقط روی گوشی کاربر و در پشتیبان شخصی او ذخیره می‌شوند و در این مخزن نیستند.

نصب: آدرس صفحه را در Chrome گوشی باز کنید و «افزودن به صفحهٔ اصلی» را بزنید.
