# Architecture decision records

Append-only. Each record: status, date (first commit or release that carried it), decision, reason, consequences. Dates and commits come from Git; where the deciding conversation is not recoverable this is marked. To change a decision, add a new record that supersedes the old one; never edit the old one's decision text.
